# FIFA 2019 Oyunçu Analizi

Python (Pandas, NumPy, Matplotlib, Seaborn) ilə FIFA 2019 oyunçu datası üzərində analiz və vizuallaşdırma.

## İstifadə olunan alətlər
- **Pandas / NumPy** — data təmizlənməsi və emalı
- **Matplotlib / Seaborn** — vizuallaşdırma

## Aparılan analizlər
- Data preprocessing: `Value` sütununun (€, M, K simvolları) rəqəmə çevrilməsi
- Oyunçuların pozisiya paylanması
- Yaş paylanması (histogram və KDE plot)
- İstifadə olunan ayağın (sağ/sol) qiymətə təsiri
- Pozisiya və ayağın birgə təsiri
- Beynəlxalq reputasiya və potensial arasındakı əlaqə
- Overall güc və potensial arasındakı əlaqə
- 4 paneldən ibarət yekun dashboard

## Fayllar
- `Fifa 2019 Oyunçu Analizi.ipynb` — tam analiz kodu
- `Fifa 2019.csv` — istifadə olunan dataset
